# Security policy

## Supported versions

OpenSKU currently provides security fixes on the latest `main` branch until versioned releases are published. Users should stay current with `main` and review release notes once tagged releases become available.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability.

Use GitHub's private vulnerability-reporting flow at:

https://github.com/CheungkiCheung/opensku/security/advisories/new

Include the affected component, reproduction steps, impact, and any suggested mitigation. Avoid including real API keys, private datasets, or other sensitive user information.

We will acknowledge a complete report as soon as practical, investigate it, and coordinate disclosure after a fix or mitigation is available.
