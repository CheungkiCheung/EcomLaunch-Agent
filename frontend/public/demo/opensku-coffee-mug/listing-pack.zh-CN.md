# 样例商品页素材包——便携旅行咖啡杯

> Demo 文案草稿。所有性能声明都必须根据最终实物完成验证后才能发布。

## 定位假设

**一款面向通勤者的日常小巧咖啡杯：减少泼洒和占用空间，又不需要携带大容量水杯。**

这是等待验证的定位假设，不是已经成立的市场结论。

## 工作标题

通勤便携咖啡杯——轻量、小巧杯架友好设计与易清洁杯盖

## 商品页卖点草稿

1. **为通勤场景设计：**小巧轮廓面向随身包、办公桌和日常移动场景。
2. **更简单的饮用流程：**在忙碌早晨用更少步骤完成打开、饮用和关闭。
3. **易清洁杯盖概念：**减少隐藏缝隙，让日常拆洗更直观。
4. **轻松日常携带：**目标成品重量低于 350 克，以最终工程确认结果为准。
5. **更克制的视觉存在感：**温暖简洁的配色适合办公室、汽车和移动场景。

## 异议处理

| 可能的问题               | 安全文案草稿                                                                           |
| ------------------------ | -------------------------------------------------------------------------------------- |
| “放在包里会漏吗？”       | 只有最终商品通过已记录的防漏流程后才能发布相关声明；优先展示测试，而不是使用绝对措辞。 |
| “能放进我的杯架吗？”     | 提供精确底部直径和适配指南，不使用“适配所有杯架”。                                     |
| “杯盖难清洗吗？”         | 使用短且未经剪辑的视频展示拆装和清洗。                                                 |
| “为什么不买更大的水杯？” | 强调小巧携带和具体使用场景，不声称普遍优于所有大容量产品。                             |
