# 历史前端评估报告（已归档）

## 一、项目概况

| 维度 | 数据 |
|------|------|
| **技术栈** | Next.js 19 + React 19 + Tailwind CSS 4 |
| **组件数量** | 280+ TypeScript/React文件 |
| **UI框架** | Radix UI + Lucide Icons |
| **状态管理** | TanStack Query + React Hooks |
| **代码规范** | ESLint + Prettier |

## 二、前端结构

```

├── app/                    # Next.js App Router
```
