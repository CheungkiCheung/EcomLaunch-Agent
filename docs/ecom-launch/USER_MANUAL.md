## 产品简介

### 什么是GrowthEngine？

GrowthEngine是一个**AI用户增长引擎**，基于多Agent协作架构，通过公开信号（Reddit、YouTube、Hacker News、Polymarket）自动生成产品增长验证包。

### 解决什么问题？

| 问题 | 传统方式 | GrowthEngine |
|------|----------|--------------|
| 没有后台数据 | 无法验证 | ✅ 公开信号验证 |
| 竞品分析耗时 | 手动搜索整理 | ✅ 自动聚合分析 |
| 用户痛点难找 | 人工访谈 | ✅ 社交媒体挖掘 |
| 增长策略主观 | 拍脑袋决策 | ✅ 证据驱动决策 |

### 核心价值

1. **多Agent协作** - 5个专业Agent并行工作
2. **证据驱动** - 基于真实数据，非主观判断
3. **自动化产出** - 7件套增长验证包
4. **可扩展** - 通用架构，适用于任意产品

## 核心功能

### 5个专业Agent

| Agent | 职责 | 输入 | 输出 |
|-------|------|------|------|
| **market-voc-researcher** | 市场研究 + 用户声音 | 产品idea | 市场洞察、用户痛点 |
| **offer-architect** | 增长策略 + 假设验证 | 市场数据 | 增长策略、验证假设 |
| **growth-analyst** | 数据分析 + 指标设计 | 市场数据 | 北极星指标、实验设计 |
| **asset-studio** | 内容创作 + 素材制作 | 增长策略 | 文案、内容、素材 |
| **evidence-checker** | 证据审计 + 质量控制 | 所有产出物 | 审计报告、置信度 |

### 4大数据源

| 数据源 | 内容 | 费用 |
|--------|------|------|
| **Reddit** | 真实用户讨论、痛点、评价 | 免费 |
| **YouTube** | 视频评测、教程、转录 | 免费 |
| **Hacker News** | 技术讨论、开发者观点 | 免费 |
| **Polymarket** | 预测市场、赔率数据 | 免费 |

### 7件套产出物

1. **launch-war-room.html** - 增长决策仪表板
2. **evidence-ledger.json** - 证据账本
3. **competitor-table.csv** - 竞品分析
4. **positioning-brief.md** - 增长策略
5. **listing-pack.md** - 产品文案
6. **content-pack.md** - 增长内容
7. **launch-calendar.csv** - 7天验证计划

## 快速开始

### 环境要求

- Python 3.12+
- Node.js 22+
- yt-dlp（YouTube搜索）
- ffmpeg（YouTube转录）

### 安装步骤

```bash
# 1. 克隆仓库
git clone git@github.com:CheungkiCheung/EcomLaunch-Agent.git
cd EcomLaunch-Agent

# 2. 安装依赖
make install

# 3. 启动服务
make dev

# 4. 访问前端
open http://localhost:2026
```

### 首次使用

1. 打开浏览器访问 `http://localhost:2026`
2. 在对话框输入你的产品idea
3. 系统会自动调用5个Agent并行分析
4. 等待2-3分钟，获取完整增长验证包

## 常见问题

### Q1：系统需要什么配置？

**A**：最低配置：
- Python 3.12+
- Node.js 22+
- 4GB RAM
- 网络连接

### Q2：需要API密钥吗？

**A**：核心功能不需要。免费数据源：
- Reddit（公开JSON）
- Hacker News（公开API）
- Polymarket（公开API）
- YouTube（yt-dlp）

可选付费源：
- X/Twitter（免费通过浏览器cookie）
- TikTok/Instagram（100次免费）

### Q3：支持中文吗？

**A**：目前主要支持英文数据源。中文平台（小红书、抖音、淘宝）正在开发中。

### Q4：分析结果准确吗？

**A**：系统使用公开信号验证，所有数据都有来源标注。但请注意：
- 公开数据可能不完整
- 建议结合人工判断
- 证据都有置信度标签

### Q5：可以用于哪些产品？

**A**：适用于任何需要验证的产品：
- SaaS产品
- 电商产品
- 移动应用
- 硬件产品
- 服务产品

### Q6：如何提高分析质量？

**A**：
1. 提供更多背景信息
2. 明确目标用户
3. 上传相关数据
4. 指定分析重点

### Q7：产出物可以修改吗？

**A**：可以。所有产出物都是可编辑的markdown/csv/json格式。

### Q8：如何分享结果？

**A**：
- launch-war-room.html 可直接分享
- 其他文件可导出为PDF
- 支持复制粘贴到文档
